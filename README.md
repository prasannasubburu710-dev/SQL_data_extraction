SQL Data Extraction

This project demonstrates how to extract and analyze sales data using SQL, SQLite, and Python Pandas.

Tools Used

- Python
- SQLite
- Pandas
- SQL

Work Done

- Created a sales database and tables.
- Performed SQL queries for filtering, sorting, grouping, and aggregation.
- Used JOIN, subqueries, CTEs, views, and ranking.
- Analyzed sales by product, customer, month, and city.
